# Subwise

Website, guides and support for **[Subwise](https://nkiro33.github.io/subwise/)**, a browser extension that keeps your Reddit subreddit, search and user feeds working after Reddit ends RSS on November 13, 2026, with unread counts, filters, notifications and keyword alerts.

Chrome, Edge and Firefox versions are in store review.

## Guides

- [Reddit RSS is gone: how to keep following subreddits](https://nkiro33.github.io/subwise/reddit-rss-alternative.html)
- [Replace Reddit search RSS feeds](https://nkiro33.github.io/subwise/replace-reddit-search-rss.html)
- [Move your Reddit feeds out of Feedly, Inoreader or NetNewsWire](https://nkiro33.github.io/subwise/import-reddit-feeds.html)
- [Reddit keyword alerts after GummySearch](https://nkiro33.github.io/subwise/reddit-keyword-alerts.html)
